기능 3개를 만들어 2개만 배포하고 1개는 test에 남긴 한 사이클. dev·test·uat·prod 4개 환경이 모두 실제로 배포됐고, UAT에서 검증한 컨테이너 이미지가 그대로 prod에 나갔다는 것을 OCI digest로 증명했다. 조립 PR 1건이 배포를 정확히 1회만 돌린 것, 충돌을 한 번 풀어 3곳에 자동 재적용된 것, test를 통째로 버리고 다시 만들어도 기능의 SHA가 보존되는 것까지 실측했다.
